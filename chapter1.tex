\chapter{Real numbers, complex numbers, quaternions, and vectors.}

\section{Number lines, planes, spaces, and hyperspaces.}

\textbullet \; The 2-dimensional real number plane, aka the real Euclidean plane. \\



This plane is simply a mathematical object. It can also be thought of as a 2-dimensional vector space over
\(\mathbb{R}\). It doesn't do anything more than define all of the points, i.e. ordered pairs \((x,y)\) of real numbers,
which can be found inside of it. It says nothing about;

\begin{itemize}[itemsep=0pt]
    \item how the points inside of it can be accessed,
    \item operations that can be performed on the points,
    \item how the axes are related to each other,
    \item how arithmetic on its points works.
\end{itemize}

One of the problems with the space \(\mathbb{R}^2\), is that it doesn't have a natural multiplication operation.

% Don't look too much into this plane. It is nothing more than a mathematical object which contains the set of all ordered
% pairs \((x,y)\) of real numbers. It says nothing about the operations that can be performed on the numbers which reside
% within it, or how the two real numbers lines are related to each other.\\

In order to impose some structure onto this plane, we need to use something like the Cartesian co-ordinate system, or
the Polar co-ordinate system. Both of these are systems which can access points within \(\mathbb{R}^2\). \\

\textbullet \; The complex number plane. \\

Next consider the complex numbers. Recall that they have the general form;

\begin{equation*}
    z = a + \qi b
\end{equation*}
\vspace{0\baselineskip}

From this, we can see that complex numbers can also be represented as pairs of real numbers; in this case it would be
\((a,b)\). It should be noted however, that unlike Cartesian co-ordinate pairs of numbers, complex numbers are not
ordered. It is one of the properties that number systems lose as they transition from real numbers to complex numbers.
But since the complex numbers can also be represented as pairs of real numbers, they too can exist within
\(\mathbb{R}^2\). \\

Just as the Cartesian co-ordinate system or the Polar co-ordinate system can be used to add meaning onto \(\mathbb{R}^2\), so we
need to add a different meaning onto \(\mathbb{R}^2\) for the complex numbers. Doing this results in a new structure which
is denoted as \(\mathbb{C}\). Among other things, this new structure tells us that one of the axes in the plane is imaginary. As a result of
this, if we multiply a value from one axis with a value from the other, we will end up with rotation. This is something
that we don't get with the Cartesian co-ordinate system, and is one of the reasons why we need to add a different
meaning onto \(\mathbb{R}^2\) than we did for the Cartesian co-ordinate system. \\

Mathematically, we can write this 2-dimensional complex plane as follows;

\begin{equation*}
    \mathbb{C} = \left\{a + \qi b \;\, | \;\, a,b \in \mathbb{R} \right\}
\end{equation*}


\section{Denoting vectors and quaternions.}

In this article, we will denote quaternions using uppercase letters, while vectors will be denoted using either lowercase
or uppercase letters which have been adorned with a right pointing arrow above them. Examples of how vectors will be denoted are
shown immediately below;

\begin{equation*}
\vec{v} \quad \vec{V} \quad \vec{q} \quad \vec{Q}
\end{equation*}
