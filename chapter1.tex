\chapter{Real numbers, complex numbers, quaternions, and vectors.}

\section{Number lines, planes, spaces, and hyperspaces.}

\textbullet \; The real number line. \\

Consider all of the real numbers. They can be thought of as belonging to or forming a set of numbers which
mathematicians denote as \(\mathbb{R}\). Alternatively, all of the numbers in this set can be imagined as living or
residing on a line, which mathematicians call the real number line. \\

Mathematically, we can write the definition of this set or line as follows;

\begin{equation*}
    \mathbb{R} = \left\{x \;\, | \;\, x \in \mathbb{R} \right\}
\end{equation*}
\vspace{0\baselineskip}

\textbullet \; The real number plane, aka the 2-dimensional real number plane. \\

Now consider what would happen if we took two of these real number lines and arranged them so that they were;

\begin{itemize}[itemsep=0pt] % [label=\alph*)]
    \item perpendicular to each other, and
    \item intersecting each other at 0 on their axes.
\end{itemize}

If we did this, then we would end up with a 2-dimensional real number space; that is, a 2-dimensional real number plane.
In such a case, the two axes which comprise the plane would usually be denoted as \(x\) and \(y\), while the
resulting plane is denoted as \(\mathbb{R}^2\). \\

Mathematically, we can write this 2-dimensional plane as follows;

\begin{equation*}
    \mathbb{R}^2 = \left\{(x,y) \;\, | \;\, x,y \in \mathbb{R} \right\}
\end{equation*}
\vspace{0\baselineskip}

This plane is simply a mathematical structure. It doesn't do anything more than define all of the points, i.e.
ordered pairs \((x,y)\) of real numbers, which can be found inside of it. It says nothing about;

\begin{itemize}[itemsep=0pt]
    \item how the points inside of it can be accessed,
    \item operations that can be performed on the points,
    \item how the axes are related to each other,
    \item how arithmetic on its points works.
\end{itemize}

% Don't look too much into this plane. It is nothing more than a mathematical object which contains the set of all ordered
% pairs \((x,y)\) of real numbers. It says nothing about the operations that can be performed on the numbers which reside
% within it, or how the two real numbers lines are related to each other.\\

In order to associate additional meaning with this plane, we need to use something like the Cartesian co-ordinate
system, or the Polar co-ordinate system. Both of these are systems which can access points within \(\mathbb{R}^2\). \\

\textbullet \; The complex number plane. \\

Next consider the complex numbers. Just like the ordered pairs \((x,y)\) of real numbers which we saw a moment ago, complex
numbers can also be represented as pairs of real numbers. Note that we said pairs of real numbers -- not ordered pairs
of real numbers. This is one of the properties that numbers lose as they transition from real numbers to complex
numbers. However, since the complex numbers can also be represented as pairs of real numbers, they too can exist within
\(\mathbb{R}^2\). \\

Just as the Cartesian co-ordinate system was needed in the previous section, to add meaning onto \(\mathbb{R}^2\), so we
need add a different meaning onto \(\mathbb{R}^2\) for the complex numbers. Doing this results in a new structure which
is denoted \(\mathbb{C}\). This new structure tells us that one of the axes in the plane is imaginary. As a result of
this, if we multiply a value from one axis with a value from the other, we will end up with rotation. This is something
that we don't get with the Cartesian co-ordinate system, and is one of the reasons why we need to add a different
meaning onto \(\mathbb{R}^2\) than we did for the Cartesian co-ordinate system. \\


\section{Denoting vectors and quaternions.}

or uppercase letters which have been adorned with a right pointing arrow above them. Examples of how vectors will be denoted are
shown immediately below;
